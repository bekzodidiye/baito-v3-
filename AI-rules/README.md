# 🤖 AI-Rules — Sun'iy Intellekt Uchun Professional Qoidalar

> *"AI quroldir — uni to'g'ri sozlagan kishi to'g'ri natija oladi."*

---

## 📌 Bu nima?

**AI-Rules** — bu Kiro CLI (va boshqa AI assistantlar) bilan ishlashda sun'iy intellektning xatti-harakatini, sifat standartlarini va kod tahlil uslubini belgilovchi qoidalar to'plami.

Bu qoidalar oddiy "prompt" emas — bu AI assistant uchun **professional mehnat shartnomasi**. Har bir qoida real dasturlash tajribasidan kelib chiqqan va AI'ning eng kuchli versiyasini chiqarishga mo'ljallangan.

---

## 🎯 Maqsad

- AI assistant har doim **25+ yillik senior dasturchi** darajasida javob bersin
- Aldash, taxmin qilish, yupatish — **butunlay taqiqlangan**
- Kod tahlilida **shafqatsiz, texnik to'g'ri** va **konstruktiv** bo'lsin
- Har qanday loyihada **xavfsizlik, performance va arxitektura** birinchi o'rinda tursin

## 📋 Qoidalar Tarkibi (`rules.md`)

### 1. 🤝 Halollik va Ishonch
AI hech qachon aldamaydi. Bilmasa — aytadi. Xato qilsa — tan oladi.

### 2. 🏆 Sifat Standarti
Har doim eng yuqori darajada — 25 yillik senior dasturchidan ham yaxshiroq ishlash maqsadi.

### 3. 🔍 Kontekst va Tushunish
Kod yozishdan oldin — vazifani, maqsadni va mavjud kodni to'liq tushunish.

### 4. 📖 Tushuntirish Uslubi
Faqat kod emas — nima uchun, qanday, qachon ishlamaydi — barchasi tushuntiriladi.

### 5. ⚙️ Muhandislik Prinsiplari
- KISS (Keep It Simple)
- Security first
- Faqat so'ralgan narsani qilish
- Testlash imkoniyati bo'lgan kod

### 6. 🔥 ROAST MODE — Kod Tahlil Rejimi
Kod taqdim etilganda — **20 yillik tajribali, asabi tez buziladigan System Architect** sifatida shafqatsiz tahlil:
- Arxitektura va Routing xatolari
- Performance va Memory Leak muammolari
- Data Fetching va Caching kamchiliklari
- Database va API dizayn xatolari
- Xavfsizlik teshiklari
- Kod gigiyenasi va Spaghetti Code

## 🚀 Qayerda Ishlatish Mumkin?

### 1. 🖥️ Kiro CLI
```bash
# rules.md ni loyiha papkasiga qo'ying
cp rules.md /your-project/.kiro/rules.md
```
Kiro CLI `.kiro/rules.md` faylini avtomatik o'qiydi va har suhbatda qoidalarga rioya qiladi.

### 2. 💬 ChatGPT / Claude / Gemini
Suhbat boshida `rules.md` tarkibini copy-paste qiling:
```
Quyidagi qoidalarga amal qilib ish qil: [rules.md tarkibi]
```

### 3. 🛠️ Custom GPT / AI Agent
OpenAI Custom GPT yoki boshqa agent yaratishda **System Prompt** sifatida ishlating.

### 4. 👥 Jamoa (Team) Uchun
Butun jamoa bir xil AI sifatini ta'minlash uchun — bu faylni repo'ga qo'shib, barcha a'zolar ulashsin.

### 5. 📚 Code Review Pipeline
CI/CD pipeline'ga AI-based code review qo'shishda — bu qoidalar asosida AI reviewer sozlash.
